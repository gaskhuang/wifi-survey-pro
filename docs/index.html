All-in-One

一個 App，涵蓋整個勘測流程

從環境掃描到驗收報告，工程師現場需要的每一步都在這裡。

現場一鍵診斷

一鍵跑完連線品質、頻道、安全、效能全項檢查，算出 0–100 健康分數與評級，並列出優先排序的問題清單。

頻譜分析儀

每個 AP 一條 bell-curve 即時頻譜，加上時間瀑布圖。含 3D 立體瀑布、Max Hold 峰值保持、移動平均與 Peak Search。

3D 瀑布 · 錄製回放

覆蓋熱圖

上傳平面圖、逐點走測，自動內插生成 RSSI / SNR / 品質分數熱力圖與等高線，一眼看出覆蓋死角。

連線穩定度分析

長時間追蹤 RSSI/SNR 波動、斷線與漫遊事件，配合閘道/外網 ping，量化連線到底穩不穩。

網路效能測試

Ping 延遲、Jitter 抖動、封包遺失、DNS 與 HTTP 響應一次量測，對照企業標準門檻自動評級。

iperf3 吞吐量測試

內建 iperf3 伺服器/用戶端管理，實測 TCP/UDP 真實吞吐量，附 QR code 快速配對行動裝置。

頻道分析

2.4 / 5 / 6 GHz 各頻道壅塞分數、同頻干擾熱區偵測，直接推薦最空的頻道配置。

即時訊號監控

多色即時折線圖持續追蹤各 AP 的 RSSI 與 SNR，停止後依整段穩定度給出建議。

PDF 勘測報告

一鍵匯出含熱圖、數據與建議的專業 PDF 報告，交付客戶或存檔驗收。

Workflow

四步完成一次現場勘測

掃描環境

開啟 App 即自動掃描周遭所有 AP，看清頻道分布與鄰居密度。

走測覆蓋

上傳平面圖、逐點記錄訊號，生成整場覆蓋熱圖。

測效能與穩定度

跑 Ping/iperf3/穩定度，確認實際體驗是否達標。

拿建議與報告

每項測試附優化建議，最後一鍵匯出 PDF 交付。
